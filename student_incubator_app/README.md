# VentureNest Student / Incubator Mobile App

Standalone Mobile Application for Students, Founders, and Incubatees.

- Port: 3000
- Features: Mobile Bottom Navigation Bar, Document Submission Vault, Guided Project Intake Wizard, Artifact Studio with explicit version approval buttons, Financial Runway Slider Calculator, and Mobile AI Assistant Drawer.

## Running Locally

```bash
npm install
npm run dev
# Mobile App opens at http://localhost:3000
```
