# VentureNest Mentors Connection Mobile App

Standalone Mobile Application for Startup Mentors, Industry Advisors, and Incubator Directors.

- Port: 3001
- Features: Mobile Bottom Navigation Bar, Incubatee Startup Directory, Pitch Deck & Document Inspector with 1-tap advisory status tags (`Approved`, `Needs Revision`), Help Request Resolution Queue, AI Document Summarizer for Mentors, and Direct Q&A Chat.

## Running Locally

```bash
npm install
npm run dev
# Mobile App opens at http://localhost:3001
```
